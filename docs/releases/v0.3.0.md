# Dance v0.3.0

Dance now supports ACME enrollment management over HTTPS with an independent API
bearer credential.

## Enrollment API

- Discover provisioners, directory URLs and EAB requirements through `/api/v1`.
- Create EAB credentials with a one-time HMAC response, inspect metadata and
  invalidate unused keys. Reuse the same idempotency key after a timeout;
  retries return metadata without repeating the secret.
- Use an API admin token for enrollment management across provisioners, or
  scoped, expiring and revocable machine credentials for restricted access.
- Find operational instructions at `/llms.txt` and the OpenAPI contract at
  `/api/v1/openapi.json`.

Set `DANCE_API_ADMIN_TOKEN_FILE` to a private token file, or supply
`DANCE_API_ADMIN_TOKEN` through your secret manager. Use a random credential of
at least 32 characters, independent of browser, session and CA credentials.
File-backed token rotation and removal take effect on subsequent requests.
Production API administration requires an HTTPS `DANCE_BASE_URL`.

See the [enrollment guide](https://github.com/rcarmo/go-dance/blob/v0.3.0/docs/agent-enrollment.md)
for configuration, request examples, recovery and Caddy integration.

## Command line

One executable provides the server and optional local credential administration:

```text
dance
dance serve
dance admin grant …
dance admin revoke …
```

## Compatibility and security

- Enrollment mutations support embedded Badger v1/v2. Proxy and shared SQL
  backends return `unsupported_backend` for these operations.
- Target/reference labels organise enrollment records; they do not restrict
  certificate DNS names. Credential creation does not configure a target host.
- Existing browser login, CA identities, provisioner names, accounts and keys
  remain compatible. Back up both the Dance and CA databases before upgrading.
- Builds use Go 1.27.4, including the fix for GO-2026-6859 in `net/http`.

Downloads include Linux and Windows binaries for AMD64 and ARM64, with SHA-256
checksums. Container images support Linux AMD64 and ARM64.
