# Dance v0.2.5

Fixes embedded ACME signed-request/EAB registration failures from [PR #1](https://github.com/rcarmo/go-dance/pull/1), updates certificate-verification and HTML-processing dependencies, and ships the locked Nix packaging added after v0.2.4. Public configuration and persistence formats are unchanged.

## Embedded ACME fixes

- Preserve the full public request path during Smallstep routing so JWS protected URLs match the request being validated; signatures are not rewritten or validation bypassed.
- Give `/acme` and `/2.0/acme` separate linkers so each directory, account and order URL retains the prefix used by the client.
- Set only empty file-configured ACME provisioner IDs to their existing `GetID()` value before authority initialisation. Admin-created EAB keys and Smallstep's EAB validator now use the same provisioner ID. Explicit IDs are preserved.
- Add an isolated embedded-authority regression using real ES256 JWS and HS256 EAB signatures. It verifies nonce/directory URLs, missing-EAB rejection, successful account and order creation, POST-as-GET authorization reads and mismatched signed-URL rejection for both prefixes.

The regressions failed on the original code and passed with the combined PR/security candidate, including the full race suite. Live certificate issuance against a deployed CA still requires an operator acceptance check; no deployed CA state or keys were touched.

## Security fixes

- Upgrade the minimum Go version and both Docker builders to 1.27.3, addressing [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809). Go's certificate verifier now rejects the known compromised intermediate certificates covered by the upstream denylist, including cases where a system trust store has not yet been updated.
- Upgrade x/net 0.61.0 → 0.62.0, addressing [GO-2026-6866](https://pkg.go.dev/vuln/GO-2026-6866) and [GO-2026-6860](https://pkg.go.dev/vuln/GO-2026-6860) in imported HTML-processing code.
- The post-update scan reports zero reachable vulnerabilities and zero advisories in imported packages. The existing module-only advisory for unused, unmaintained OpenPGP remains documented; that package is not imported or shipped by Dance.

## Packaging fixes

- Add `flake.nix` and `flake.lock` for Linux x86-64 and ARM64, with default/named packages, a runnable app, package checks, a development shell and formatting.
- Pin nixpkgs and the Go module vendor hash. The flake selects its pinned Go 1.27 toolchain, currently 1.27.3, matching the application's updated minimum.
- Run the complete unit suite and release-target regressions through `make test` in Nix builds. Patch generated test-helper shebangs to use Nix's Bash rather than an unavailable `/usr/bin/env` inside the build sandbox.
- Set the Nix package version to 0.2.5 and ignore generated Nix result symlinks.

```sh
nix build
nix flake check
nix develop
```

Nix must have `nix-command` and `flakes` enabled. Runtime CA material, administrator credentials and application state stay outside the immutable Nix store; builds and development-shell setup do not provision a live CA.

## Release policy

Linux AMD64 and ARM64 binaries and images use matching native Linux runners. Windows binaries are cross-compiled on those Linux runners. Darwin targets remain omitted to save GitHub Actions costs; no Darwin or Windows runners are used. Apple certificate-enrollment support is unchanged.

## Upgrade

This release retains the [v0.2.3 security fixes and dependency refresh](https://github.com/rcarmo/go-dance/releases/tag/v0.2.3). Production deployments require a persistent, cryptographically random `DANCE_SESSION_KEY` of at least 32 bytes. Explicitly set `DANCE_DEVELOPMENT_MODE=true` for temporary local runs using an ephemeral key.

No new application features were added, and Bouncer is unchanged.
