# Dance v0.2.4

Publishes the native Linux release pipeline requested after v0.2.3. Application code, dependency versions and persistence formats are unchanged from v0.2.3.

## Release targets

| Target | Builder |
|---|---|
| Linux AMD64 / Intel | Native `ubuntu-24.04` runner |
| Linux ARM64 | Native `ubuntu-24.04-arm` runner |
| Windows AMD64 | Cross-compiled on the AMD64 Linux runner |
| Windows ARM64 | Cross-compiled on the ARM64 Linux runner |

Darwin/macOS release targets are omitted to save GitHub Actions costs. No Darwin or Windows runners are used. macOS/iOS certificate-enrollment support is unchanged.

Both native Linux jobs verify the host and Go architecture before packaging. Each produces its Linux archive and matching Windows ZIP; the publication job combines the four archives and generates one checksum manifest. Container images are also built on native AMD64 and ARM64 Linux runners.

Already-compressed intermediate archives use zero additional compression and one-day artifact retention to limit Actions overhead and storage costs.

## Upgrade

This release includes the [v0.2.3 fixes and dependency refresh](https://github.com/rcarmo/go-dance/releases/tag/v0.2.3). Production deployments still require a persistent, cryptographically random `DANCE_SESSION_KEY` of at least 32 bytes. Temporary local runs must explicitly enable `DANCE_DEVELOPMENT_MODE=true` to use an ephemeral key.

Go remains at 1.27.2. No new application features were added. Bouncer is unchanged at v0.2.1; its images already use native AMD64 and ARM64 Linux runners.
