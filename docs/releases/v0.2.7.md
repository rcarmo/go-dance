# Dance v0.2.7

Fixes Linux root-certificate installation on machines that do not yet trust the CA, and keeps long directory URLs inside their overview cards. Go 1.27.3, dependencies and persistence formats are unchanged from v0.2.6.

## Fixes

- Embed the configured root certificate in the Linux enrollment helper instead of downloading it with `curl`. Installing the root no longer requires an HTTPS connection that already trusts it. Certificate validation still runs before installation; no TLS verification bypass is added.
- Return 404 for the Linux helper when no root certificate is available.
- Document trusted-channel delivery, fingerprint verification and manual installation for older helpers. Download a fresh helper after root rotation. The installer itself must come from a trusted source; embedded certificates cannot authenticate an unverified script.
- Add shell-execution regressions for the embedded root, validation failures and absent root certificates. Tests stub privileged operations and do not modify system trust.
- Allow stat cards to shrink and wrap long values, including ACME directory URLs, without clipping or changing their contents.
- Align the Nix package version with v0.2.7.

## Upgrade

Download a new `/enroll/linux.sh` helper from a trusted Dance deployment. Previously downloaded scripts still contain the old HTTPS download step. If the deployment's HTTPS certificate is not trusted yet, obtain the script or root certificate through a trusted channel and verify it with the CA operator before installation. Do not use `curl -k` to obtain a root certificate or executable installer you intend to trust.

No deployed CA configuration, private keys, provisioner IDs, accounts or EAB state are renamed or migrated. Existing provisioner names and directory URLs remain unchanged.

## Release policy

Linux AMD64 and ARM64 binaries/images use matching native Linux runners. Windows binaries are cross-compiled on those Linux runners. Darwin targets remain omitted to save GitHub Actions costs; no Darwin or Windows runners are used. Apple and Windows enrollment behaviour is unchanged.
